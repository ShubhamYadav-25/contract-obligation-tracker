# Render Deployment

This repository is ready to deploy through a Render Blueprint using the root
`render.yaml`.

## Services

- `contract-obligation-tracker-api`: Node web service for the Express API,
  embedded worker, and scheduler.
- `contract-obligation-tracker-web`: Render static site for the Vite frontend.

The frontend is built with:

```bash
corepack pnpm --filter @contract-obligation-tracker/web run build
```

The API is built and started with:

```bash
corepack pnpm --filter @contract-obligation-tracker/api run build
corepack pnpm --filter @contract-obligation-tracker/api run start:render
```

`start:render` applies workflow migrations from the compiled output before
starting `dist/src/server.js`.

## Required Render Secrets

Set these in the Render Blueprint creation flow or in the API service
environment settings:

- `DATABASE_URL`: PostgreSQL connection string. Use the Supabase pooler URL if
  keeping the current Supabase database setup.
- `SUPABASE_URL`: Supabase project URL.
- `SUPABASE_SERVICE_ROLE_KEY`: Supabase service-role key.
- `SUPABASE_STORAGE_BUCKET`: Private bucket used for contract PDFs.
- `GROQ_API_KEY`: Optional if `OBLIGATION_EXTRACTOR_MODE=auto`; without it the
  API falls back to heuristic extraction.

`JWT_SECRET` is generated by Render from the Blueprint.

## Default Render URLs

The checked-in Blueprint assumes these service names and public URLs:

- API: `https://contract-obligation-tracker-api.onrender.com`
- Web: `https://contract-obligation-tracker-web.onrender.com`

If Render assigns a different hostname or you rename either service, update
these values in `render.yaml` and redeploy:

- API service: `APP_BASE_URL`
- API service: `CORS_ORIGIN`
- Web static site: `VITE_API_BASE_URL`

Vite reads `VITE_API_BASE_URL` at build time, so changing it requires a frontend
rebuild.

## Health Check

Render checks:

```text
/health
```

Expected response:

```json
{
  "success": true,
  "data": {
    "status": "ok",
    "service": "contract-obligation-tracker-api"
  }
}
```

## Notes

- The API supports Render's `PORT` variable. If `API_PORT` is not set,
  `PORT` is used.
- The static site rewrites all routes to `/index.html` for React Router.
- Do not copy local `.env` secrets into git. Use Render environment variables
  or Blueprint `sync: false` prompts for secret values.
