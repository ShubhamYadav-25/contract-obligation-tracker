Confidence levels:

- HIGH: direct code evidence and low likelihood of intentional dynamic use.

- LOW: weak evidence, high dynamic/runtime uncertainty, or high removal/refactor risk.

## Manual Verification Notes

- Findings from `02-unused-candidates.md` influenced frontend interpretation: several duplicate-looking React components and hooks are tied to old or unreachable pages. Consolidation should wait until router/API ownership is decided.
- Dynamic runtime wiring can hide valid consumers. The audit did not mark provider adapters, migrations, fixtures, CLI scripts, KPI datasets, reminder scenarios, or state-machine test cases as removable due to duplicate-looking code.
- No temporary dependency tool was permanently installed. The architectural results above are based on direct source inspection and existing repository files.
