# Unused Candidates Audit

Date: 2026-07-21

Input inventory: `docs/repository-audit/01-repository-inventory.md`

Scope: read-only dead-code and dependency audit. No source files were removed or runtime behavior changed. Existing repository inspection used `rg`, package manifests, route/bootstrap files, and manual verification of dynamic registries, package scripts, migrations, CLI entry points, and planned provider interfaces.

## Audit Notes

- Applied migrations were not marked removable.
- Working-subset contract PDFs, CUAD manifest, state-machine tests, and test fixtures were not marked removable solely because they are not imported.
- Environment-selected or clearly planned provider interfaces were treated as higher-risk candidates.
- Frontend code that is only unreachable because the current router points to `features/workflow/pages.tsx` is reported separately from hard-dead utility files.
- No dependency was confirmed as safely unused. Most package dependencies are referenced by source, tests, Vite/Tailwind/PostCSS config, or package scripts.
